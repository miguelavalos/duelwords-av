# Security Policy

## Reporting A Vulnerability

Do not report security vulnerabilities through public GitHub issues.

Use GitHub private vulnerability reporting for this repository when available.
If that channel is unavailable, open a minimal public issue asking maintainers
to enable a private reporting channel. Do not include exploit details, room or
invite data, targets, guesses, tokens, private endpoints, or personal data.

## Sensitive Configuration

Do not commit Account AV credentials, Convex deploy keys, Cloudflare secrets,
signing material, private runtime configuration, real room data, or
signed-runtime evidence.
