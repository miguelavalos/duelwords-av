# Contributing

Contributions must preserve the client-safe boundaries documented in
[`AGENTS.md`](./AGENTS.md).

Before opening a pull request:

1. keep changes focused;
2. run `pnpm verify` and `pnpm lint`;
3. keep connected runtime disabled by default;
4. do not include private configuration or production evidence;
5. update public documentation when client-visible behavior changes.

Report vulnerabilities through the private process in
[`SECURITY.md`](./SECURITY.md).
